📅 Follow-ups in your calendar Google · Outlook · Apple

Every open follow-up shows up as an all-day event on the day it's due (read from the note: "call her back Friday" → Friday). Done ones disappear. Sensitive cases show only a number, never details.

Subscribe on this device
Or by hand

Calendar apps check for changes on their own schedule: Apple and Outlook every hour or so, Google can take up to a day. For one follow-up right now, use the 📅 button next to it on the dashboard.

🗣️ Log without opening the app Siri · Android share

"Hey Siri, log impact" (iPhone)

Build it once in the Shortcuts app, about 2 minutes:

  1. New shortcut. Name it Log impact
  2. Add Dictate Text
  3. Add Get Contents of URL, with the address below. Tap ▸: Method POST, Request Body JSON, add fields text = Dictated Text, worker = your name, channel = voice
  4. Under Headers add Authorization = the value below
  5. Add Get Dictionary Value: key confirmation, then Speak Text

Share to ImpactText (Android)

Once the app is on the home screen, text from any app (Messages, Gmail, Google Keep, WhatsApp) can be sent to it: select the text → Share → ImpactText. It opens with the note filled in; check it and tap Save.

Long-press the ImpactText icon for a Log something shortcut.

🔒 About these links

The calendar and spreadsheet links work without the app password, because calendar apps and Google Sheets can't log in. Anyone with a link can read what it shows, so share them like a password. If one leaks, make new links: the old ones stop working at once (update them where you added them).
